# LyriWave

LyriWave is a desktop application for creating lyric videos.

This repository is the official public distribution repository for LyriWave releases published by Lunovia.

## Official Website

Product information, screenshots, system requirements, setup instructions, known limitations, and support information are available on the official Lunovia LyriWave page:

https://lunovia-apps.github.io/apps/lyriwave/

## Download

Download LyriWave only from the official Lunovia website or the official GitHub Releases page for this repository.

**GitHub Releases:**

https://github.com/lunovia-apps/lyriwave/releases

The current release is:

**LyriWave 1.0.0**

- Platform: Windows x64
- Primary target: Windows 11
- Windows 10: Best effort
- Installer: `LyriWave_1.0.0_x64-setup.exe`

LyriWave 1.0.0 is distributed as an unsigned Windows application. Windows may display a security warning when launching the installer.

For download information and the current release details, see:

https://lunovia-apps.github.io/apps/lyriwave/

## FFmpeg Requirement

LyriWave requires FFmpeg and ffprobe for audio import and MP4 export.

FFmpeg and ffprobe are not included with LyriWave and must be obtained separately.

Setup instructions are available on the official LyriWave page:

https://lunovia-apps.github.io/apps/lyriwave/
